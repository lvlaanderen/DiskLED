#### Version 3.2.0 (fork) ####

- Temperature meters, without extra software or drivers. The wizard has two new choices: "Computer temperature" shows one of the sensors (thermal zones) the computer reports to Windows, for example near the processor, and "Graphics card temperature" shows the temperature the graphics driver reports, as in Task Manager. Only sensors and graphics cards that report a temperature are listed, with their current value. Temperatures are shown in Celsius or Fahrenheit, a new meter uses the unit of your region.
- Disk meters now show how busy the disk is, like "Active time" in Task Manager, and no longer go above 100%. The counter they used (% Disk Time) is based on how many requests are waiting and goes far above 100% on fast SSDs. New disk meters use % Idle Time with Invert. Your existing disk meters are not changed: to switch, choose Disk in the quick pick, or set the counter to % Idle Time (Invert is then ticked for you).
- A meter with Invert is named after what it shows: % Idle Time becomes "% Active Time", Available MBytes becomes "Used MBytes", other counters get "100% minus" in front. The tooltip also shows what the value is computed from.


#### Version 3.1.0 (fork) ####

- Every meter has its own update interval (Appearance page). A processor meter can update ten times a second while a download speed meter updates once a second. A reading covers the meter's whole interval, so a network speed is the average of that second rather than of the last few milliseconds. Choosing a data source fills in a suitable interval: 30 ms for disks, 100 ms for processors, 1 second for network speeds, memory and other counters. Your existing meters keep the interval they had.
- Tray icons can now be moved one by one. Windows 11 treated the icons of all meters as one, so dragging one icon out of the overflow area took all of them along and they could not be put in another order. If you used version 3.0, the meters other than the first appear as new icons once: drag each to where you want it.


#### Version 3.0.0 (fork) ####

Several meters in one program:
- Until now every counter needed its own folder with its own program and settings file. Now one DiskLED shows as many meters as you like, each one as its own icon in the tray. You can move and promote the icons individually.
- A second counter is now simply a second meter, with its own icon. Your existing settings are converted when you first save them, a file with a second counter becomes two meters.
- Every meter has its own data source, icon type, colours, scale and warning, and an optional name that is shown in its tooltip and in warnings. The update interval is shared.
- A counter that cannot be read (for example a network adapter that is not there) only affects its own icon. The other meters keep running.

Easier setup:
- A wizard adds a meter in three steps: what to monitor (internet download or upload speed, disk, processor, memory or another counter), which adapter, disk or processor, and how it looks, with a preview.
- Import from an older DiskLED: the wizard finds copies of version 1.x and 2.x (in their Start with Windows entries, the Startup folder and among the running programs, or you choose their DiskLED.ini) and takes over the meters you select, with their icon, colours, scale and warnings. The older copies are not changed or stopped. If you like, their Start with Windows entries are removed. When DiskLED starts for the first time and finds an older copy, it offers the import.
- The settings window lists the meters on the left. Changes are shown on the tray icons right away. Save keeps them, Revert goes back, and closing with unsaved changes asks what to do. The Update INI checkbox and the Apply button are gone.
- All messages follow the Windows theme (dark or light), not only the settings window.
- The settings window opens on the screen where you clicked the tray icon.

Settings and installation:
- The settings are now stored in %AppData%\DiskLED\DiskLED.ini, so DiskLED can be installed in a folder that you cannot write to, such as Program Files. A DiskLED.ini next to the program from an older version is copied there the first time.
- Portable use: a file called "portable" next to DiskLED.exe keeps the settings next to the program, as before. The zip download contains this file.
- There is an installer now. It lets you choose between Program Files (all users) and a folder for the current user, and offers to start DiskLED with Windows. The zip stays available for portable use.
- Only one DiskLED runs per user. Starting it again opens the settings of the running one. There is a single Start with Windows entry, an entry of an older version for the same program is replaced.
- If you ran several copies of DiskLED in several folders (version 1.x or 2.x): the wizard can take over their meters, see "Import" above. On the first start DiskLED offers this by itself when it finds an older copy.

Changed:
- INI files: the settings of a meter are in a section [Meter n], the update interval is in [General]. See the README. Older files are still read.


#### Version 2.1.0 (fork) ####

Settings in DiskLED.ini from version 2.0 and older keep working. Version 2.0 stays available on the releases page.

A new configuration dialog:
- Four tabs: Data source, Scale and values, Appearance and Alerts. The icon type and the live preview stay visible on every tab.
- Follows the Windows app theme: dark or light, also while the dialog is open. The About dialog and the tray menu follow it too (Windows 10 version 1809 or later).
- Sharp on high-DPI screens. The tray icons are drawn at the real tray icon size.

Easier setup:
- Quick pick: choose Internet download speed, Internet upload speed, Disk activity, Processor use or Memory in use, and DiskLED fills in the counter, the units and the scale. For the internet speed it finds the network adapter that connects to the internet.
- Choosing a counter in the lists now fills in sensible defaults too: 100 for percent counters, the installed memory for memory counters, and so on. You can change everything afterwards.
- The 100% field accepts units, for example 350 Mbit/s or 50 MB/s. A plain number still works.
- For network counters the dialog shows the speed of the network adapter, with a button to use it as the 100% value. This is the speed of the adapter, not of your internet connection.

New scale: Auto
- DiskLED learns the highest value it sees and uses it as the full icon. The value is remembered in DiskLED.ini (LearnedMax) and falls very slowly, by half in a day.
- The 100% value is the minimum scale. For network counters the learned value never exceeds the speed of the adapter.

Changed:
- Warnings are now measured against the scale, the value that fills the icon, not against the 100% value. With the Fixed scale nothing changes. With Peak, Decay and Auto, 80% now means 80% of the full icon.

Fixed:
- The icon and the tooltip could stop updating after Explorer restarted, the taskbar changed or Windows came back from standby. The tray icon is now added again when Windows loses it, and the counters reconnect after standby, after several unusable values in a row and when all values stay at zero for a minute.


#### Version 2.0.0 (fork) ####

Based on the source code of DiskLED 1.1.1 by Helge Klein.

New icon types. All icons are now drawn at runtime, so they follow your colours:
- LED, Bar (Task Manager style), Clean bar, VU meter, Graph and Number
- Choose the colours for low, medium and high load, and the percentages where they change
- A live preview in the configuration dialog

Showing numbers and units:
- The tooltip always shows the current value
- Value formats: percent, plain number, bytes/s, bits/s and megabytes (MB/GB/TB)
- Invert: show the 100% value minus the counter, e.g. memory used from memory available
- Scale: fixed, peak of the last 16 values, or a peak that slowly decays

Two counters:
- Show a second counter, e.g. download and upload speed
- Bar types share one icon, the graph uses one icon with two halves, the number gets two tray icons

Warnings:
- Show a notification when a value stays above a threshold for a set time

Other improvements:
- "Start with Windows" option in the configuration dialog (per user, no admin rights needed)
- Counter paths in the INI file are stored in English and work on any Windows language. Paths in the system language from older versions still work.
- If the counters cannot be read, DiskLED shows the red exclamation mark with the problem in the tooltip and keeps trying to reconnect
- Percentage counters are no longer capped at 100%
- Settings in the INI are validated, applying settings that do not work keeps the previous ones
- Built with Visual Studio 2022, requires Windows 7 or later (the x64 build needs a 64-bit Windows)

Settings in DiskLED.ini from older versions keep working.

#### Version 2.0.0 (fork) ####

Based on the source code of DiskLED 1.1.1 by Helge Klein.

New icon types. All icons are now drawn at runtime, so they follow your colours:
- LED, Bar (Task Manager style), Clean bar, VU meter, Graph and Number
- Choose the colours for low, medium and high load, and the percentages where they change
- A live preview in the configuration dialog

Showing numbers and units:
- The tooltip always shows the current value
- Value formats: percent, plain number, bytes/s, bits/s and megabytes (MB/GB/TB)
- Invert: show the 100% value minus the counter, e.g. memory used from memory available
- Scale: fixed, peak of the last 16 values, or a peak that slowly decays

Two counters:
- Show a second counter, e.g. download and upload speed
- Bar types share one icon, the graph uses one icon with two halves, the number gets two tray icons

Warnings:
- Show a notification when a value stays above a threshold for a set time

Other improvements:
- "Start with Windows" option in the configuration dialog (per user, no admin rights needed)
- Counter paths in the INI file are stored in English and work on any Windows language. Paths in the system language from older versions still work.
- If the counters cannot be read, DiskLED shows the red exclamation mark with the problem in the tooltip and keeps trying to reconnect
- Percentage counters are no longer capped at 100%
- Settings in the INI are validated, applying settings that do not work keeps the previous ones
- Built with Visual Studio 2022, requires Windows 7 or later (the x64 build needs a 64-bit Windows)

Settings in DiskLED.ini from older versions keep working.

#### Version 1.1.1 ####

#### Version 1.1.0 ####

- Added a graphical configuration dialog, accessible by right-clicking the icon in the taskbar
  - The dialog lets you choose from any performance counter found on the local system
  - Now everything is configurable both from a GUI and an INI file
- Added a nicer about dialog
- Whenever there is a problem displaying data, the icon changes to a red exclamation mark

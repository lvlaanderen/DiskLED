#### Version 2.1.0 (fork) ####

Settings in DiskLED.ini from version 2.0 and older keep working. Version 2.0 stays available on the releases page.

A new configuration dialog:
- Four tabs: Data source, Scale and values, Appearance and Alerts. The icon type and the live preview stay visible on every tab.
- Follows the Windows app theme: dark or light, also while the dialog is open. The About dialog and the tray menu follow it too (Windows 10 version 1809 or later).
- Sharp on high-DPI screens. The tray icons are drawn at the real tray icon size.

Easier setup:
- Quick pick: choose Internet download speed, Internet upload speed, Disk activity, Processor use or Memory in use, and DiskLED fills in the counter, the units and the scale. For the internet speed it finds the network adapter that connects to the internet.
- Choosing a counter in the lists now fills in sensible defaults too: 100 for percent counters, the installed memory for memory counters, and so on. You can change everything afterwards.
- The 100% field accepts units, for example 350 Mbit/s or 50 MB/s. A plain number still works.
- For network counters the dialog shows the speed of the network adapter, with a button to use it as the 100% value. This is the speed of the adapter, not of your internet connection.

New scale: Auto
- DiskLED learns the highest value it sees and uses it as the full icon. The value is remembered in DiskLED.ini (LearnedMax) and falls very slowly, by half in a day.
- The 100% value is the minimum scale. For network counters the learned value never exceeds the speed of the adapter.

Changed:
- Warnings are now measured against the scale, the value that fills the icon, not against the 100% value. With the Fixed scale nothing changes. With Peak, Decay and Auto, 80% now means 80% of the full icon.

Fixed:
- The icon and the tooltip could stop updating after Explorer restarted, the taskbar changed or Windows came back from standby. The tray icon is now added again when Windows loses it, and the counters reconnect after standby, after several unusable values in a row and when all values stay at zero for a minute.


#### Version 2.0.0 (fork) ####

Based on the source code of DiskLED 1.1.1 by Helge Klein.

New icon types. All icons are now drawn at runtime, so they follow your colours:
- LED, Bar (Task Manager style), Clean bar, VU meter, Graph and Number
- Choose the colours for low, medium and high load, and the percentages where they change
- A live preview in the configuration dialog

Showing numbers and units:
- The tooltip always shows the current value
- Value formats: percent, plain number, bytes/s, bits/s and megabytes (MB/GB/TB)
- Invert: show the 100% value minus the counter, e.g. memory used from memory available
- Scale: fixed, peak of the last 16 values, or a peak that slowly decays

Two counters:
- Show a second counter, e.g. download and upload speed
- Bar types share one icon, the graph uses one icon with two halves, the number gets two tray icons

Warnings:
- Show a notification when a value stays above a threshold for a set time

Other improvements:
- "Start with Windows" option in the configuration dialog (per user, no admin rights needed)
- Counter paths in the INI file are stored in English and work on any Windows language. Paths in the system language from older versions still work.
- If the counters cannot be read, DiskLED shows the red exclamation mark with the problem in the tooltip and keeps trying to reconnect
- Percentage counters are no longer capped at 100%
- Settings in the INI are validated, applying settings that do not work keeps the previous ones
- Built with Visual Studio 2022, requires Windows 7 or later (the x64 build needs a 64-bit Windows)

Settings in DiskLED.ini from older versions keep working.
